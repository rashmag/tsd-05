# Релиз

Обновление публикуется в [rashmag/tsd-05](https://github.com/rashmag/tsd-05/releases). ТСД смотрит только последний опубликованный релиз: `GET /repos/rashmag/tsd-05/releases/latest`. Черновик и prerelease в эту выборку не попадают.

Проверка идёт при запуске приложения. Debug-сборка её не делает.

## Как выложить

1. Соберите release APK.
2. Создайте релиз и прикрепите APK. Приложение берёт файл с типом `application/vnd.android.package-archive`.
3. Заполните два разных поля.

**Tag** — версия. По нему ТСД понимает, что сборка новее установленной. Пишите как раньше, например `v5.4.9`. Маркер `[force]` в tag не ставится.

**Release title** — можно ли пропустить установку.

| Поведение на ТСД | Release title |
|---|---|
| Окно можно закрыть | `v5.4.9` |
| Окно закрыть нельзя | `v5.4.9 [force]` |

`[force]` ищется в любом месте заголовка, регистр не важен: `[force] v5.4.9` и `v5.4.9 [FORCE]` работают так же.

## Как это видит ТСД

Если tag новее установленной версии, показывается окно.

Без `[force]` в заголовке три кнопки: «Обновиться сейчас», «Может позже», «Не интересно». Последние две закрывают окно до следующего запуска. «Назад» окно не закрывает.

С `[force]` остаётся только «Обновиться сейчас». «Назад» окно не закрывает. Если отказаться от разрешения на хранилище или установку из неизвестных источников, окно открывается снова.

Если заголовок релиза прочитать не удалось, окно показывается как необязательное.
